# Ananth Industry - Bill App

A single-page billing app for shops — create bills, track payments, manage stock, and print receipts via Bluetooth thermal printer.

## Hosting on GitHub Pages

1. Upload `index.html` to the root of this repository.
2. Go to **Settings → Pages**.
3. Under **Source**, select your main branch and the `/ (root)` folder, then save.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.

## Notes

- Keep the file named `index.html` — GitHub Pages serves that as the homepage automatically.
- No build step or server needed; it's a static HTML file.
